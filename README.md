# Brain Tumor Detection App

This application leverages deep learning (VGG19) to detect brain tumors from MRI scans.  
It is designed as an educational and research tool to demonstrate how AI can assist in medical imaging and diagnostics.

---

## Features
- Upload MRI images easily  
- Instant predictions with confidence score  
- Clear output (Tumor / No Tumor)  
- Interactive and user-friendly UI  

---

## Model Highlights
- Architecture: VGG19  
- Input Size: 150×150 pixels  
- Output: Binary classification (Tumor / No Tumor)  
- Dataset: Brain MRI Dataset (Tumor vs Healthy)  

---

## Note
This application is intended for **educational and research purposes only**.  
It should not be used as a substitute for professional medical diagnosis.
